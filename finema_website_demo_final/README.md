# Finema Real Estates Group Ltd — Website Concept

This is a front-end concept/demo made with:
- HTML
- CSS
- JavaScript

## How to open
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Double-click `index.html` to open it in a browser.
3. For development, use VS Code and the Live Server extension if available.

## Before presenting or publishing
- Confirm the company's official name and legal details.
- Verify both recruitment email addresses.
- Add the official phone/WhatsApp number.
- Replace concept content and placeholder visual elements with approved company photos.
- Connect the recruitment form to a secure backend or a verified form service.
- Obtain permission before publishing the website as the company's official website.


## Logo and WhatsApp updates
- `finema-logo.png` contains a cropped version of the logo from the supplied flyer.
- The floating WhatsApp button is included.
- Replace `REPLACE_WITH_OFFICIAL_NUMBER` in `script.js` with Finema's verified WhatsApp number before publishing.
- Confirm that you have permission to use the logo and company branding.
